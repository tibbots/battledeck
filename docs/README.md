— stack, build and delivery, working practice — stays in [`../CLAUDE.md`](../CLAUDE.md), and that
file is deliberately short enough to read whole.

The documents fall into two groups, and the difference is not their subject but their reach.

## What this is not for

Not a diary. What stands here has to still hold on the next read; a measurement that turns out to
be wrong gets corrected, not placed beside the old one. What an element used to look like is in
`git log` — a past state is written down only where it is the warning itself, i.e. where somebody
would otherwise re-introduce a removed hazard.

And not a place for procedures. What somebody *executes* — a release, a screenshot run, driving the
app or the game — is a skill in [`../.claude/skills/`](../.claude/skills/), because a procedure has
a first step and a last one and wants to be followed, not read.

## The rule these documents share

**Measured, not assumed.** Every number here comes from a run against the real game or the real
app. Where something is guessed, it says so. Two numbers that only agree at one sample are one
number and a coincidence — which is why anchors are verified at two resolutions, rotation periods
at two years, and vocabulary against the running client rather than from memory.
